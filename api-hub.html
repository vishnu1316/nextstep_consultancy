MySQL 8.0 Relational Architecture

Designed in Third Normal Form (3NF) with foreign keys linking users, student profiles, admissions, university catalog, and counsellor bookings.

users

Stores credentials, role-based auth (student, counsellor, admin), and bcrypt hash.

student_profiles

Linked to users(user_id). Academic GPA, IELTS score, passport details.

universities

Global catalog with country index, rankings, tuition range, and acceptance rate.

applications

Central transaction table linking student, university, course with status & stage.

counselling_appointments

Schedules student sessions with advisor ID, date, time slot, and mode.

Backend Architecture & Technical Specifications

1. API & Security Architecture

  • RESTful Design: Standard HTTP Verbs (GET, POST, PUT, DELETE) with semantic status codes (200, 201, 400, 401, 500).
  • JWT Authentication: Bearer tokens issued on login, signed with HMAC-SHA256 secret.
  • CORS Handling: Cross-Origin Resource Sharing enabled for seamless frontend decoupling.
  • Document File Handling: Multi-part file upload support (Multer) for PDF passports, transcripts, and SOPs.

2. How to Run Locally for Presentation

# 1. Start the Node backend server
node server.js

# 2. Server will launch on:
http://localhost:3000

# 3. Test health check:
curl http://localhost:3000/api/health
